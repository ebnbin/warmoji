# ⚔️ Warmoji

emoji 幸存者：割草生存 web 小游戏，全部代码由 Claude 通过聊天驱动开发。

**玩法**：操控 😎 走位躲避涌来的 🧟👻，飞刀 🔪 自动攻击，吃 💎 升级强化，活得越久越强也越危险。桌面用 WASD/方向键，手机用虚拟摇杆。

- 技术栈：Vite + TypeScript + Phaser 3
- 线上地址：https://warmoji.ebnbin.dev （备用：https://warmoji.vercel.app）

开发约定见 [CLAUDE.md](./CLAUDE.md)，玩法设计见 [docs/GDD.md](./docs/GDD.md)。
