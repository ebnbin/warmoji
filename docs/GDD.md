## 候选方案：emoji 幸存者（割草生存）

吸血鬼幸存者（Vampire Survivors）式的单机生存游戏：

- 玩家操控一个 emoji（如 😎）在开放场地走位，武器全自动攻击。
- 敌方 emoji（🧟 👻 🎃 💀 🤖 …）成群涌来，一波强过一波；杀敌掉落经验 💎。
- 升级时三选一强化：新武器 / 攻速 / 移速 / 攻击范围等。
- 死亡结算：存活时长 + 击杀数，记录本地最高分。
- 操作：桌面 WASD/方向键，手机虚拟摇杆。

### v0.1（首个可玩版本）范围

移动 + 一把自动飞刀 🔪 + 两种敌人 + 波次刷怪 + 血量/死亡/重开 + 计分 + 手机虚拟摇杆。
