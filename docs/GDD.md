# Warmoji 游戏设计文档

> 状态：**v0.1 已上线**。玩法方向由用户授权 agent 拍板，选定「emoji 幸存者」。

## 核心循环

吸血鬼幸存者式的单机割草生存：

1. 玩家操控 😎 在固定尺寸的竞技场（960×540，单屏）走位，武器全自动攻击；
2. 敌人从场地四边涌入、追踪玩家；杀敌掉落经验 💎，靠近会被吸附；
3. 升满经验条即升级，获得自动强化；敌人随时间更多、更快、更硬；
4. 血量归零结算：存活时长 + 击杀数 + 等级，记录本地最高分（localStorage）。

## 当前系统（v0.1）

| 系统 | 说明 |
|---|---|
| 武器 | 飞刀 🔪：定时向最近敌人投掷，可升至 6 把/轮（扇形散射） |
| 敌人 | 僵尸 🧟（慢、硬、伤害高）、幽灵 👻（快、脆、伤害低） |
| 波次 | 刷怪间隔随时间递减、敌人血量递增、幽灵占比递增（见 `src/core/waves.ts`） |
| 升级 | v0.1 无三选一 UI，按固定顺序自动强化：🔪 飞刀 → ⚡ 攻速 → 👟 移速 → ❤️ 回复循环 |
| 操作 | 桌面：WASD / 方向键；手机：浮动虚拟摇杆（按下任意处出现） |
| 结算 | 死亡遮罩 + 成绩 + 最高分 + 点击/按键重开；菜单显示历史最佳 |

全部数值集中在 `src/core/config.ts`，调参只改这一个文件。

## 已知取舍（v0.1）

- 单屏固定竞技场，无镜头滚动（后续可扩展为大地图 + 镜头跟随）；
- 手机竖屏会上下留黑边，横屏体验最佳；
- 无音效；
- 升级为自动强化，无三选一选择界面。
